# Phase 1 — Foundations

The mental models everything else stands on. Before touching PyTorch or
Hugging Face, you'll refresh the Python used in ML and build intuition for what
"learning from data" and "neural networks" actually mean — no heavy math.

## Notebooks (do them in order)

| # | Notebook | What you learn |
|---|----------|----------------|
| 01 | `01_python_refresher.ipynb` | Lists, dicts, comprehensions, functions, classes, JSON/JSONL, NumPy, and a little pandas — the exact Python you'll reuse all course |
| 02 | `02_ml_fundamentals.ipynb` | Features vs labels, train/validation/test split, overfitting, loss, gradient descent, and basic metrics |
| 03 | `03_neural_network_basics.ipynb` | Neurons, layers, activations, the forward pass, and backpropagation explained as "assigning blame" |

## After this phase you can…
- Read and write the Python patterns used in every later notebook.
- Explain supervised learning, overfitting, loss, and gradient descent in plain words.
- Describe how a tiny neural network turns inputs into predictions and learns from mistakes.

## Prerequisites
Basic Python (variables, `if`/`for`, functions). Runs on **CPU** — no GPU needed.
